# 轮腿机器人平衡控制器 (Wheel-Leg Controller)

## 1. 控制结构
本节点采用 **LQR + VMC** 的串级控制架构：
- **LQR (线性二次型调节器)**：处理机体的俯仰角(pitch)、角速度、位移和速度，计算维持倒立摆平衡所需的轮子力矩和虚拟腿力矩。
- **VMC (虚拟模型控制)**：将 LQR 输出的虚拟力 (F_0) 和虚拟力矩 (T_p) 通过五连杆正运动学雅可比矩阵，映射为两个髋关节的实际电机力矩。
- **Roll Leg Controller**：根据机体的横滚角(roll)动态分配左右腿长，防止侧翻。

## 2. K矩阵/参数来源
- **LQR K矩阵**：通过多项式拟合 `POLY_COEFFICIENT` 得到，随虚拟腿长 L0 实时变化。
- **PID参数**：腿部高度控制 PID (kp=700, kd=5)，偏航控制 PID (kp=0.5, kd=1.0)。
- **前馈补偿**：增加了 4N 的重力前馈抵消自重。

## 3. 实测数据
- **平衡时长**：实现原地平衡持续 > 5s。
- **pitch 曲线**：稳定状态下，机体 pitch 偏差 < 10°。
